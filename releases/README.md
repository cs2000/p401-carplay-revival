# Firmware downloads

**This update does not back up your current firmware. Flashing can make the unit unusable. Neither the maintainer nor this project provides a recovery firmware, recovery route, or recovery method if it fails. Use it entirely at your own risk.**

| Version | Contents | Validation |
| --- | --- | --- |
| [2026.11-w3-rc1](2026.11-w3-rc1/README.md) | Newer vendor menus + matching kernel + W2/W3 wireless fixes; no diagnostic logger; saved settings retained | Components worked in the owner's staged installation; combined image validated offline only |

Each release directory contains a USB ZIP, checksums, a manifest and release notes. Download the ZIP rather than copying repository files onto a USB. The USB ZIP contains only `update`, `zImage` and `rootfs.img` at its top level.
